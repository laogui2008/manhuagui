# 非专业Android开发人员
### 一边看官方文档，一边查资料，手动撸代码。。。。。。

一款简单的观看[漫画柜](https://www.manhuagui.com)漫画APP，没有性能测试，没有兼容性测试。  
  
站点不能访问，需要自备代理。

手头上只有两台机子：android8、android11。在android11上功能还算正常，在android8上有点问题，基于能用就行的原则，不太影响使用的问题，懒得修了。

### 不能保证在其它机子也能正常使用!!!  
  
## 关于“阅读方向”设置  

### 从左往右、从右往左  
适用于观看大部分漫画作品。  
　　
### 上下滑动  
适用于观看大部分漫画作品＋被分割成多张长图(如:800x10000像素)的长条漫，如：拥抱星星的剑士。  
　　
### Webtoon  
适用于观看被分割成很多张小图片的长条漫，如：我独自升级、最强暗杀者异世界转移。
   
　　
### 在长滚动列表，双击TAG可以快速回到顶部
### 在观看漫画时，双击中间区域，可以放大图片，再次双击还原。在放大图片时，可以单指拖动图片、双指缩小(放大)图片
### 在观看漫画时，当阅读方向设置为“从左往右（从右往左）”时，点击屏幕左、右两侧，可返回上一页(如果不是第一章节的第1页，则是返回上一章节)，或进入下一页(如果不是最后章节的最后1页，则是进入下一章节)。当阅读方向设置为“上下滑动”时，点击屏幕的顶部（不显示跳页、设置情况下）、底部，如果不是第一章节的第1页，则是返回上一章节，如果不是最后章节的最后1页，则是进入下一章节。  
  
### APP是没有嵌入任何广告内容的！  
  
### 请不要相信视频中出现的任何广告内容，也不要用浏览器去打开浏览！！！

说明：  
a. 从旧版本升级时，建议先导出观看记录备份。  
b. 不能观看动漫视频的，可尝试将相关域名加入代理名单中。  
c. 樱花动漫源站点的搜索功能不好用，直接复制作品标题去搜索，也有可能搜索不到结果。直接用拼音去搜索，可能会有搜索结果。  
d. 樱花动漫观看动漫视频时，大概在5分钟，会有广告内容出现，时长大概20秒、30秒。这是站点视频源问题，它的视频都是嵌入了广告内容的。有一些长视频，在中间或者结尾，也有可能嵌入了广告内容。  
e. AGE动漫的VIP播放源，大概率观看不了，网站有加密，js逆向不好搞。其它非VIP路线，视频源估计也是了嵌入了广告内容的。
